# Build plan

Text first, voice later: steps 1–4 work by typing, so the ordering logic is debugged
before audio is added.

- [x] 0. Accent test — script that sends my 10 recorded WAV files to Voxtral and local
        faster-whisper (small), prints both transcripts and the word error rate against my reference text
        RESULT: Voxtral 13.25% vs whisper 34.37%. Findings: (a) Voxtral confirmed,
        (b) fuzzy menu matching is load-bearing ("kottu"), (c) eval needs number
        normalization (step 12), (d) references must be re-recorded only for mumbles.
- [x] 1. Project setup — uv project, folder structure, `.env` for keys, config loading
- [x] 2. Menu + RAG — `menu.json` (~30 items), embed with Mistral embeddings, store locally,
        `search_menu()` function with a quick test
        DONE: fuzzy+vector hybrid. Findings: aliases make fuzzy exact ("coke"=1.00);
        vector survives heavy mangles ("seafloor flight less"->Seafood Fried Rice);
        fully-mangled kottu fails into chicken-top-3 -> step 4 prompt rule: "weak search = ask,
        never guess"; vector scores are hints, exact fields (contains_onions) remain the truth.
- [x] 3. Order state + tools — Order model, `add_item`, `update_item`, `remove_item`,
        `confirm_order`, unit tests (no LLM yet)
        DONE: 7/7 tests green. Read-back generated by Order.summary(), prices frozen
        from menu at add time, confirmed orders lock all change tools.
- [x] 4. Text agent — Mistral Small with tool calling in a terminal chat loop; place a full order by typing
        DONE: 14/14 tests + live session verified. Findings: (a) agent bug "everything has
        onions" = wrong-tool problem -> added exact filter_menu tool; similarity tools must
        never be used for whole-catalog questions; (b) prompt rules from step 2 findings
        worked as designed (ask-don't-guess, read-back-before-confirm, drinks upsell).
- [x] 5. Voice pipeline — LiveKit Agents with Voxtral STT + TTS, plug in the step 4 agent, test in browser

        Kottu mangled on 1st try -> agent ASKED (works as designed); bias fixed it on
        repeat. Follow-ups: validate LLM option args vs menu, filter_menu sloppy
        params, use_realtime=True latency retest.
- [x] 6. Barge-in — stop speaking when the caller talks; keep only the spoken part of the reply in context
        DONE: verified live. interruption detected mid-reply (agent cut itself off,
        dropped the rest); coughs correctly IGNORED (no false interruption); AEC
        warmup window confirmed. Fixes shipped with it: read_order tool (agent
        claimed "added" with no add call -> read_order exposed the empty truth,

## Project summary

Voice ordering agent for a made-up restaurant. Customer talks in the browser; agent
answers menu questions (RAG), builds the order with tool calls, handles interruptions,
reads the order back, recovers when the caller gets frustrated, saves confirmed orders
for a kitchen screen.

Stack: LiveKit Agents + WebRTC, Mistral Voxtral (STT + TTS), Mistral Small + Meta Muse
via LLM proxy, Mistral embeddings + local vector store. English only in v1.
